# Electric Wall-Hung Boiler

Space-heating support for Midea device type **C1** (validated on model **2760001Z**). This profile is heating-only; domestic hot water / bath controls from some Lua scripts are not exposed.

## Features

- Target temperature (30–60 °C, 1 °C step)
- Preset heating modes: `user`, `activity`, `sleep`
- Power on/off via climate or optional switch

## Service

### midea_ac_lan.set_attribute

[![Service](https://my.home-assistant.io/badges/developer_call_service.svg)](https://my.home-assistant.io/redirect/developer_call_service/?service=midea_ac_lan.set_attribute)

Set the attribute of appliance. Service data:

| Name      | Description                                 |
| --------- | ------------------------------------------- |
| device_id | The Appliance code (Device ID) of appliance |
| attribute | "power"                                     |
| value     | true or false                               |

| Name      | Description                                 |
| --------- | ------------------------------------------- |
| device_id | The Appliance code (Device ID) of appliance |
| attribute | "heating_mode"                              |
| value     | user, activity, or sleep                    |

Example

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: power
  value: true
```

```yaml
service: midea_ac_lan.set_attribute
data:
  device_id: XXXXXXXXXXXX
  attribute: heating_mode
  value: activity
```
